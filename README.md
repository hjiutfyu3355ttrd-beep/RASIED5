# نظام إدارة المشاريع والتشطيبات v0.1.0

نظام ويب (واجهة عربية RTL) لإدارة مشاريع التشطيبات: المخزون بمتوسط تكلفة مرجح متحرك، المشتريات، العمالة، النقل، التشوين، فواتير المشاريع، المقبوضات، وربحية المشروع/المهندس.

مبني بنفس أسلوب ومعمارية نظام السيارات (Vanilla JS + Demo localStorage / Supabase لاحقاً + PWA).

## التشغيل

```bash
cd project-system
python3 -m http.server 8000
```

ثم افتح: http://localhost:8000/

## ما يعمل حالياً (v0.1)

- لوحة التحكم (ملخص مالي + مشاريع + تنبيهات مخزون)
- المشاريع
- حركات المخزون + أرصدة بمتوسط مرجح متحرك
- ربحية المشاريع (خامات + عمالة + نقل + تشوين + مصروفات)
- بذرة بيانات مطابقة للشيت التجريبي (النتائج متطابقة: صافي ربح 12841، مخزون 17 وحدة / 901 ج)

## الربط مع Supabase

- `js/config.js` يحتوي `SUPABASE_URL` و`SUPABASE_ANON_KEY` (المفتاح العام آمن؛ الحماية عبر RLS + تسجيل الدخول). احذفهما للعودة للوضع التجريبي المحلي.
- المخطط الكامل في `supabase/migrations/20261115000001_init_schema.sql` (21 جدولاً، RLS مفعّل، فهارس، بيانات مرجعية فقط).
- الدخول: `login.html` (بريد + كلمة مرور). **أول مستخدم يُنشأ في Supabase Auth يصبح مديراً تلقائياً**، وأي مستخدم بعده يكون غير مفعّل حتى يفعّله المدير (جدول `app_users`، الحقل `active`).
- الأدوار: `admin` (كل شيء + الحذف) · `staff` (قراءة وإضافة وتعديل) · `viewer` (قراءة فقط).
- يُنصح بتعطيل التسجيل العام (Sign ups) من إعدادات Authentication في Supabase.

## v0.2 — الدخول والمستخدمون والتثبيت والتنبيهات

- **الدخول:** `login.html` برقم الهاتف (يُحوَّل لبريد داخلي `p<phone>@phone.projectserp.app`) أو بريد حقيقي. عند عدم وجود أي مستخدم يظهر تبويب «إعداد النظام» لإنشاء أول مدير (Edge Function `setup`، تُقفل تلقائياً بعد أول مستخدم).
- **المستخدمون (`users.html`، للمدير فقط):** إضافة/تعديل/إيقاف/حذف، تغيير كلمة المرور، أدوار (مدير · موظف · قراءة فقط)، صلاحيات الصفحات بقوالب جاهزة، وأيام الاستخدام ومرات الدخول وآخر دخول. العمليات الحساسة عبر Edge Function `staff` (تمنع إيقاف/حذف نفسك أو آخر مدير).
- **القيود المفروضة في قاعدة البيانات (RLS):** `deny:delete` و`deny:edit` للموظف، وقراءة فقط للـ viewer، وبيانات الشركة/الإعدادات للمدير فقط. أما **صلاحيات الصفحات فتُحجب في الواجهة فقط** (لتنظيم العمل لا كحماية من مستخدم تقني).
- **التثبيت (PWA):** `manifest.webmanifest` + `sw.js` + `offline.html` + `js/pwa.js` (لافتة تثبيت تلقائية على الموبايل، إرشاد iOS، زر تثبيت في الشريط العلوي). يتطلب HTTPS. غيّر `VERSION` في `sw.js` و`?v=` عند كل إصدار.
- **التنبيهات (`js/notify.js`):** جرس في الشريط العلوي: مخزون منخفض · مشروع متأخر · مستحقات عملاء · مستحقات موردين · خزينة بالسالب · مشروع خاسر، مع إشعارات جهاز محلية (تظهر عند فتح التطبيق). Web Push من الخادم (تنبيه والتطبيق مغلق) غير مفعّل بعد — `sw.js` جاهز لاستقباله.
- **Supabase:** `supabase/migrations/*` + `supabase/functions/{setup,staff}`. يُنصح بتعطيل Sign ups من Authentication.

## المنطق الصلب

- **متوسط تكلفة مرجح متحرك**: كل وارد يحدّث المتوسط، كل صادر يستخدم المتوسط الحالي.
- **تكلفة الخامات على المشروع** = صرف للمشروع − مرتجع من المشروع (+ شراء مباشر).
- **صافي ربح المشروع** = إيراد الفواتير − (خامات + عمالة + نقل + تشوين + مصروفات أخرى).
- أرصدة الخزائن والموردين محسوبة من الحركات المرتبطة.
