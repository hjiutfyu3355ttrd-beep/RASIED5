# نظام إدارة المشاريع والتشطيبات v0.1.0

نظام ويب (واجهة عربية RTL) لإدارة مشاريع التشطيبات: المخزون بمتوسط تكلفة مرجح متحرك، المشتريات، العمالة، النقل، التشوين، فواتير المشاريع، المقبوضات، وربحية المشروع/المهندس.

مبني بنفس أسلوب ومعمارية نظام السيارات (Vanilla JS + Demo localStorage / Supabase لاحقاً + PWA).

## التشغيل

```bash
cd project-system
python3 -m http.server 8000
```

ثم افتح: http://localhost:8000/

## ما يعمل حالياً (v0.1)

- لوحة التحكم (ملخص مالي + مشاريع + تنبيهات مخزون)
- المشاريع
- حركات المخزون + أرصدة بمتوسط مرجح متحرك
- ربحية المشاريع (خامات + عمالة + نقل + تشوين + مصروفات)
- بذرة بيانات مطابقة للشيت التجريبي (النتائج متطابقة: صافي ربح 12841، مخزون 17 وحدة / 901 ج)

## المنطق الصلب

- **متوسط تكلفة مرجح متحرك**: كل وارد يحدّث المتوسط، كل صادر يستخدم المتوسط الحالي.
- **تكلفة الخامات على المشروع** = صرف للمشروع − مرتجع من المشروع (+ شراء مباشر).
- **صافي ربح المشروع** = إيراد الفواتير − (خامات + عمالة + نقل + تشوين + مصروفات أخرى).
- أرصدة الخزائن والموردين محسوبة من الحركات المرتبطة.

## الخطوات القادمة

- صفحات الإدخال (فواتير مشتريات، صرف مخزون، عمالة...)
- حسابات الموردين والعملاء
- تقارير الخزينة والمخزون
- ربط Supabase + صلاحيات
- استيراد/تصدير
