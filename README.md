# نظام إدارة المشاريع والتشطيبات v0.4.0

نظام ويب (واجهة عربية RTL) لإدارة مشاريع التشطيبات: المخزون بمتوسط تكلفة مرجح متحرك، المشتريات، العمالة، النقل، التشوين، فواتير المشاريع، المقبوضات، وربحية المشروع/المهندس.

مبني بنفس أسلوب ومعمارية نظام السيارات (Vanilla JS + Demo localStorage / Supabase لاحقاً + PWA).

## التشغيل

```bash
cd project-system
python3 -m http.server 8000
```

ثم افتح: http://localhost:8000/

## ما يعمل حالياً (v0.1)

- لوحة التحكم (ملخص مالي + مشاريع + تنبيهات مخزون)
- المشاريع
- حركات المخزون + أرصدة بمتوسط مرجح متحرك
- ربحية المشاريع (خامات + عمالة + نقل + تشوين + مصروفات)
- بذرة بيانات مطابقة للشيت التجريبي (النتائج متطابقة: صافي ربح 12841، مخزون 17 وحدة / 901 ج)

## الشركات والحسابات (v0.3)

- **نظام شركات متعددة:** كل من يسجّل من `login.html ← حساب جديد` يحصل على **شركة بياناتها معزولة تماماً** (RLS بـ `company_id` على كل الجداول، مفاتيح مركّبة `(company_id, id)` فيمكن لأي شركتين استخدام نفس `PRJ-0001`). يُنشأ له تلقائياً: مخزن رئيسي وخزينة رئيسية وأنواع مصروفات.
- **الأدوار:** مدير المنصة (أول حساب يُسجَّل في المنصة) · مالك الشركة · موظف · قراءة فقط.
- **الدخول:** برقم الهاتف (يُحوَّل لبريد داخلي `p<phone>@phone.projectserp.app`) أو بريد حقيقي.
- **مستخدمو الشركة (`users.html`، للمالك):** إضافة/تعديل/إيقاف/حذف موظفين، تغيير كلمة المرور، صلاحيات الصفحات بقوالب، وقيود `deny:delete` و`deny:edit` **مفروضة داخل قاعدة البيانات**. صلاحيات الصفحات تُحجب في الواجهة فقط.
- **إدارة المنصة (`admin.html`، لمدير المنصة):** كل الحسابات والشركات، إيقاف/تفعيل (إيقاف المالك يوقف شركته كلها)، أيام الاستخدام ومرات الدخول وآخر ظهور وحجم بيانات كل شركة. لا يرى مدير المنصة محتوى بيانات الشركات.
- **Supabase:** `supabase/migrations/*` + Edge Functions: `register` (عامة) · `staff` (JWT، للمالك) · `send-push` (بسرّ `x-cron-secret`). الدالة `setup` ملغاة. اترك **Allow new users to sign up مقفولاً**: التسجيل يمر عبر `register`.

## التثبيت والتنبيهات

- **PWA:** `manifest.webmanifest` + `sw.js` + `offline.html` + `js/pwa.js` (لافتة تثبيت تلقائية، إرشاد iOS، زر في الشريط العلوي). يتطلب HTTPS. غيّر `VERSION` في `sw.js` و`?v=` عند كل إصدار.
- **مركز التنبيهات (`js/notify.js`):** جرس + إعدادات لكل نوع: مشاريع متأخرة · مخزون منخفض · مستحقات عملاء · مشروع خاسر · مستحق للمورد · خزينة بالسالب.
- **Web Push (يصل والتطبيق مغلق):** جداول `push_*` + دوال RPC + Edge Function `send-push` + جدولة `pg_cron` يومياً 06:00 UTC (8 صباحاً القاهرة شتاءً). مفاتيح VAPID تُولَّد داخل الخادم ولا تظهر للعميل. الخادم يرسل: مشاريع متأخرة · مخزون منخفض · مستحقات على مشاريع منتهية (الباقي داخل التطبيق فقط). لتغيير الوقت: `select cron.alter_job(<id>, schedule => '...')`، وللإيقاف: `select cron.unschedule('projects-push-morning')`. على الآيفون يعمل فقط بعد إضافة التطبيق للشاشة الرئيسية (iOS ≥ 16.4).

## المنطق الصلب

- **متوسط تكلفة مرجح متحرك**: كل وارد يحدّث المتوسط، كل صادر يستخدم المتوسط الحالي.
- **تكلفة الخامات على المشروع** = صرف للمشروع − مرتجع من المشروع (+ شراء مباشر).
- **صافي ربح المشروع** = إيراد الفواتير − (خامات + عمالة + نقل + تشوين + مصروفات أخرى).
- أرصدة الخزائن والموردين محسوبة من الحركات المرتبطة.

## ما الجديد في v0.4 (مطابقة كاملة لشيت G-P4.xlsm)

- **إصلاح مشكلة «كل صفحة تفتح لوحة التحكم»:** القائمة كانت تشير لـ 21 صفحة والموجود 7 فقط، والاستضافة كانت تُرجع `index.html` لأي رابط غير موجود. أُنشئت كل الصفحات + `404.html`.
- **شاشات الإدخال والإدارة لكل جداول الشيت:** المهندسون · المشاريع · الموردون · الأصناف · المخازن · الخزائن · أنواع المصروفات · حركات الخزينة · مدفوعات الموردين · فواتير المشاريع · مقبوضات العملاء · مصروفات المشاريع · العمالة · النقل · التشوين.
- **فاتورة المشتريات** (رأس + أصناف + خصم/ضريبة): تدخل المخزن بالمتوسط المرجح أو تُحمَّل مباشرة على مشروع، وتُحفظ كمعاملة واحدة على الخادم (`save_purchase_invoice`).
- **حركات المخزون:** صرف للمشروع · مرتجع من المشروع (بتكلفة الصرف الأصلية) · تحويل بين مخزنين · مرتجع للمورد · تسوية زيادة/عجز، مع منع الصرف بأكثر من المتاح. تكلفة الصادر تُعاد حسابها وتُخزَّن في قاعدة البيانات (`recalc_stock`).
- **التقارير:** حسابات الموردين (+ كشف حساب) · حسابات العملاء · المخزون · الخزينة (رصيد أول/آخر الفترة) · حركة الأصناف · ربحية المشاريع والمهندسين، وكلها بتصدير Excel.
- **لوحة تحكم متقدمة:** 10 مؤشرات مع مقارنة بالفترة السابقة، رسوم (إيراد/تكلفة/ربح شهرياً، تدفق نقدي، توزيع التكلفة، حالات المشاريع، أرصدة الخزائن، أعلى المشاريع، مستحقات العملاء، ترتيب المهندسين، مستحقات الموردين)، تنبيهات، آخر العمليات، فلاتر (فترة/مشروع/مهندس).
- **الإعدادات:** بيانات الشركة والقوائم + تصدير شامل Excel/JSON.
- **قاعدة البيانات:** `supabase/migrations/20261116000003_*` (مطبّقة): عمود `stock_movements.supplier_id` لمرتجعات الموردين + الدوال أعلاه + فهارس.
